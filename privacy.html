Privacy Policy

Last updated: October 2026

"Devin" is a personal, single-user application operated by Taylor Curran. Its only user is its operator; it is not distributed to or usable by the public.

Data accessed

With the operator's explicit consent, the application uses the Google Gmail API with the gmail.readonly and gmail.compose scopes to read messages in the operator's own mailbox and to create draft emails. It does not send email on its own.

Data storage and sharing

Message content is processed only to carry out the operator's requests and is not stored beyond the task at hand, sold, or shared with any third party. OAuth credentials are kept in an encrypted secret store accessible only to the operator.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
